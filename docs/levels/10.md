# Seviye 10 — Kayıt Altında

| Alan | Değer |
|---|---|
| Kavram | `tcpdump -r`, `-A`, `strings`, HTTP başlıkları |
| Hedef | Yakalanmış trafikten mühür 11'i çıkarmak |
| Süre | ~12 dakika |

## Amaç

`/srv/pcap/capture.pcap`, 1996'daki bir doğrulama konuşmasının kaydı.
Mühür, paketlerin içinde düz metin olarak duruyor.

## Kavram

`.pcap`, libpcap biçimidir: bir başlık + zaman damgalı çerçeveler. Metin
değildir, ama taşıdığı yük çoğu zaman metindir.

| Komut | Ne yapar |
|---|---|
| `tcpdump -r dosya` | paketleri tek satırda özetler |
| `tcpdump -r dosya -A` | yükleri ASCII olarak basar |
| `tcpdump -r dosya -X` | yükleri hex + ASCII basar |
| `strings dosya` | kayıttaki tüm metin parçalarını listeler |
| `tshark -r dosya -Y http` | protokol bazlı filtreleme (kurulu değilse gerekmez) |

HTTP başlıkları `Anahtar: değer` biçimindedir; `-A` çıktısında bu satırlar
okunur haldedir. Uzun bir konuşmada gözle aramak yerine `sed`/`grep` ile
daraltın.

## İpuçları

1. `file /srv/pcap/capture.pcap`
2. `tcpdump -r /srv/pcap/capture.pcap -A | grep -i seal`
3. `tcpdump -r /srv/pcap/capture.pcap -A | sed -n 's/.*X-Archive-Seal: *//p'`
