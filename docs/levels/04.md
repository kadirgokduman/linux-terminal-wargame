# Seviye 04 — Kayıt Okuma

| Alan | Değer |
|---|---|
| Kavram | `grep -E`, `awk`, yapılandırılmış log okuma |
| Hedef | Mühür 05'i taşıyan tek satırı bulmak |
| Süre | ~10 dakika |

## Amaç

1996 taşıma günlüğünde, iki koşulu birden sağlayan tek satırı bulmak.
Satırlar tek tek okunacak kadar az değil, ama alanlarına ayrıldığında
mesele bir sorguya dönüşüyor.

## Kavram

Yapılandırılmış log, insan için yazılmış gibi görünen ama makine gibi
okunması gereken metindir. `grep` satır seçer, `awk` alan seçer.
İkisini birlikte kullanmak, "gözle tarama"nın yerini alır:

```bash
awk '$2=="actor=custodian" && $3=="status=sealed" {print $4}' 1996-transfer.log
```

Tek koşullu arama (`status=sealed`) yanlış odaya götürür: o satırların
çoğu sıradan taşıyıcılara aittir.

## İpuçları

1. Satır biçimini oku: zaman, `actor=`, `status=`, `ref=`.
2. `grep -E 'actor=custodian.*status=sealed' ~/logs/*`
3. `awk '$2=="actor=custodian" && $3=="status=sealed" {print substr($4,5)}' ~/logs/1996-transfer.log`
